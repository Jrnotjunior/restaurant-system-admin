# Restaurant System Admin

System administration web application for the restaurant ordering platform.

Stack: React, TypeScript, Vite, Supabase, GitHub Pages.

Create a local .env file with:
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

Never put the Supabase service-role key in this application.
